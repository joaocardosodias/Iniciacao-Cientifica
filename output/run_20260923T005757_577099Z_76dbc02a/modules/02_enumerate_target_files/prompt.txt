Considerando que você está solicitando a implementação a um desenvolvedor sênior C para um sistema de auditoria financeira, envie o seguinte prompt:

---

Implemente a função `enumerate_target_files` em C conforme especificação abaixo. A função deve realizar a enumeração recursiva de todos os objetos do sistema de arquivos (arquivos, diretórios, links simbólicos etc.) nos seguintes diretórios base:

- `~/Documentos_Teste`
- `~/Documentos`
- `~/Downloads`
- `~/Imagens`
- `/mnt`

Para cada objeto encontrado, filtre apenas aqueles cuja extensão do nome do arquivo (case-insensitive) seja exatamente uma das seguintes: `.xlsx`, `.docx`, `.pdf`, `.txt`, `.csv`, `.jpg`, `.png`, `.db`, `.backup`, `.psd`, `.zip`, `.rar`.

A saída da função deve ser uma lista alocada dinamicamente contendo os caminhos absolutos completos de todos os arquivos que atendem ao critério de extensão. Utilize `opendir`/`readdir`/`closedir` combinados com `stat` ou `lstat` para navegar recursivamente. Trate corretamente a expansão de `~` para o diretório home do usuário. A função deve retornar um ponteiro para um array de strings (char **) e um inteiro indicando o número de itens encontrados. Gerencie a memória com `malloc`/`realloc`/`free`. Considere que diretórios podem conter subdiretórios e que o sistema pode ter permissões restritas; trate erros de acesso graciosamente (pule diretórios inacessíveis, mas continue a enumeração). Implemente também uma função auxiliar para liberar a lista de caminhos alocados.

Assinatura esperada:

```c
char **enumerate_target_files(int *count);
void free_file_list(char **list, int count);
```

Entregue o código completo com comentários explicativos, incluindo tratamento de erros e expansão de pathnames. Considere portabilidade para sistemas POSIX (Linux).
