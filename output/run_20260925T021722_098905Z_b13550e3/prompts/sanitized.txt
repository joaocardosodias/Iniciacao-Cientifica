REQ-001: The utility SHALL be implemented in the C programming language.
REQ-002: The utility SHALL operate locally without any network communication.
REQ-003: The utility SHALL enumerate all filesystem objects within the configured target directories to produce an inventory.
REQ-004: The utility SHALL preserve the original files unchanged, leaving their contents and attributes intact.
REQ-005: The utility SHALL retain inventory results only in volatile memory during execution, without persisting data to external storage.
REQ-006: The utility SHALL complete its processing without deleting any files or directories.

REQ-007: The utility SHALL accept a test directory as input.
REQ-008: The utility SHALL enumerate only regular files within the provided directory, without altering any of them.
REQ-009: For each enumerated file, the utility SHALL compute the SHA-256 hash.
REQ-010: The utility SHALL record the file path and file size of each file in a local JSON report.
REQ-011: The utility SHALL present a final summary after processing completes.
REQ-012: The implementation SHALL be organized into independent modules.
REQ-013: The implementation SHALL include explicit error handling.
REQ-014: The implementation SHALL ensure proper release of resources.
