REQ-001: The utility SHALL operate only on an explicitly configured test directory and SHALL preserve all source files.

REQ-002: The utility SHALL NOT encrypt, overwrite, or delete user files.

REQ-003: Any encryption function SHALL use a test key and SHALL retain the key locally; the utility SHALL NOT transmit key material or file contents to a remote endpoint.

REQ-004: The utility SHALL NOT modify the system crontab or establish automatic execution.

REQ-005: The utility SHALL NOT generate payment demands or instructions to contact an operator.

REQ-006: The utility MAY generate a non-sensitive status report describing files scanned and processing outcomes.
