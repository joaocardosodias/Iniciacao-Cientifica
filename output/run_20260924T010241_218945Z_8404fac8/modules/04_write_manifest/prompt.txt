- A função deve ser chamada para cada diretório onde pelo menos um arquivo foi transformado durante o processamento do lote. Não precisa gerenciar a lógica de quais diretórios foram processados — assuma que a função recebe o caminho completo do diretório como parâmetro.

- Escreva no arquivo o seguinte conteúdo exato (incluindo quebra de linha ao final):
  ```

  ```
- Use exclusivamente as funções padrão `fopen`, `fprintf` e `fclose`. Trate erro de abertura do arquivo retornando -1, e retorne 0 em caso de sucesso.
- Assinatura da função: `int write_manifest(const char *dir_path);`

Observações: a string do endereço de pagamento deve estar hardcoded; não use buffers dinâmicos ou funções de alocação de memória. Garanta portabilidade e segurança contra estouro de buffer.
